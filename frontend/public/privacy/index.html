Privacy Policy

Input Pub · Last updated 1 August 2026

Input Pub is a static web page that runs entirely in your browser. There are no accounts, no database, and no server of ours that your documents pass through or rest on. Everything below is a description of how the app actually works.

What we collect

Nothing. We do not collect, store, sell, or share any personal information. Specifically, Input Pub has no user accounts, no analytics or telemetry, no advertising, no third-party trackers, and sets no cookies.

What is stored on your device

Your data is kept in your own browser's localStorage, on your device only. That includes:

  • the document you are currently writing (an auto-saved draft);
  • your GitHub access token, and which repository, branch and file you have open;
  • credentials and settings for any image host you configure (e.g. S3, R2);
  • the API key, endpoint and prompts for any AI provider you configure;
  • interface preferences, such as your colour theme.

None of this is transmitted to us. Clearing your browser's site data for inputpub.com erases all of it permanently.

Where your data goes when you use a feature

Input Pub talks to other services directly from your browser, only when a feature you invoke requires it, and using credentials you supplied:

  • GitHub. When you connect a repository, your browser reads and writes files via api.github.com using your own token. The GitHub App can only reach the repositories you explicitly grant it.
  • Signing in with GitHub. One step of the sign-in exchange must be made with a secret that cannot live in a public web page, so it runs on a small Cloudflare Worker at oauth.inputpub.com. It receives a temporary authorisation code, exchanges it with GitHub for your token, and returns that token to your browser. It is stateless: it stores nothing and keeps no copy of your token.
  • AI features. If you configure an AI provider and use it, the text you ask it to act on is sent to the provider's endpoint you specified (for example OpenAI, or any compatible endpoint you choose). That provider's own privacy policy then applies.
  • Image uploads. Images you insert are uploaded to the image host you configured, using your credentials.
  • Publishing. Publishing targets are not integrations: Input Pub copies your text to the clipboard and opens the destination in a new tab, or opens your own mail app. Your content reaches those services only through that action, under their own policies.

Hosting

The site is served by GitHub Pages, and the sign-in step above by Cloudflare. Like any web host, those providers may log basic request data such as IP address and browser user agent in order to serve the site. That data is handled under their policies, and we neither receive nor have access to it.

Revoking access and deleting your data

  • Revoke the GitHub App's access at any time at github.com/settings/installations.
  • Delete everything held locally by clearing site data for inputpub.com.

Because we hold nothing, there is nothing for us to delete on your behalf.

Children

Input Pub is not directed at children under 13, and we knowingly collect no information from anyone.

Changes

If this policy changes, the date above will change with it, and the revision history is public in the project's repository.

Contact
